# Calcio 📱✨

**Calcio** is a premium, high-performance Calculator and Unit Converter application built with Flutter. Designed with a stunning glassmorphic interface, dynamic aurora background, and delightful micro-animations, it offers both basic and scientific mathematical operations.

## ✨ Features

- **Advanced Calculator Engine:** Supports basic arithmetic, complex scientific operations (sin, cos, tan, log, ln, sqrt, etc.), percentages, factorials, and constants (π, e) with robust error handling.
- **Unit Converter:** Seamlessly convert between Weight, Length, Temperature, Data, and Volume.
- **Glassmorphic UI:** High-end visual design with a dynamic aurora background, blurred overlays, and a premium dark mode color palette.
- **Haptic Feedback:** Tactile responses on button presses for an enhanced user experience.
- **Calculation History:** Automatically saves your calculation history persistently.
- **Memory Functions:** Standard memory operations (MC, MR, M+, M-).
- **Particle Animations:** Delightful particle burst effects when a calculation completes.

## 🛠 Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** `ChangeNotifier` (Controller Pattern)
- **Local Storage:** `shared_preferences`
- **Parsing Engine:** `math_expressions`
- **Fonts:** `google_fonts`

## 🚀 Getting Started

1. Ensure you have the Flutter SDK installed.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to launch the app on your connected device or emulator.

## 🧪 Testing

Calcio comes with a comprehensive test suite covering the calculation engine and its edge cases.

To run the tests:
